## Project Overview

This project focuses on building an AI-based system capable of solving multiple-choice questions (MCQs). The goal is to predict the top three most probable answers for each question using machine learning and natural language processing techniques.

The project will explore data preprocessing, model development, evaluation, and answer ranking methods.
